## Evidence labels and scope

- **Source**: route/component behavior inspected in the current working tree. It does not establish deployed behavior.
- **Observed**: the coordinator reported a fresh public-browser or live boundary check, with its bounded scope below.
- **Fixture**: isolated local checks, with synthetic or absent data and no account/API/provider/chain connection. They do not prove a real financial flow.
- **Pending**: the check has not been established for the combined public revision. A specified state is not automatically a passed state.

Source coverage and test specifications can complete the RSI-007 inventory criteria without completing RSI-093’s full responsive/accessibility/provenance audit. Read-only identity/data evidence can satisfy RSI-078 without completing purchase, transfer, reward, resale or withdrawal UAT.

## Approved financial and data boundaries

The pinned API artifact version is 0.1.0; OpenAPI SHA-256 is `484aa0635357fea37de78b6c32607c0b680c5c355b5d06fa0216e925204e36c2`. [api-manifest.json](../../artifacts/platform/api-manifest.json), the generated DTOs and the schema must agree. The actual browser transport is [client.ts](../../src/lib/platform/client.ts) through the [fixed BFF](../../src/lib/platform/proxy.ts); generated interfaces do not authorize a request by themselves.

Live backend mode uses [server.ts](../../src/lib/platform/server.ts) and [auth/session.ts](../../src/lib/auth/session.ts) for request-time identity, cookies and no-store reads. PlatformProvider scopes its cache by user and stops child screens on session/wallet mismatch. Browser financial values use validated strings/BigInt; fixed display FX is 1 USDT = 3.6 reAED with rounding only at display. They are not payment instructions in dollars. No provider private token, secret, key, identity record or financial amount belongs in this audit.
